# JadePuffer (Storm-3168) Azure Cloud Attack

![Banner](banner.jpg)

Microsoft Threat Intelligence has documented an active campaign by Storm-3168, deploying the JadePuffer malware framework to compromise Azure cloud environments. This financially motivated threat actor leverages sophisticated lateral movement techniques and compromised credentials to hijack cloud resources for cryptomining and data exfiltration.\n\nOur latest threat briefing covers the technical mechanics of the JadePuffer payload, the specific Azure attack vectors exploited by Storm-3168, and the critical identity and access management (IAM) controls security teams must implement immediately.\n\nRead the full technical breakdown and mitigation strategies on our official security portal.
